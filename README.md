# signqueue

Sign encode/decode helpers for queue payloads in pipelines.

**Site:** https://theworker02.github.io/signqueue/

## Install / run

```bash
git clone https://github.com/theworker02/signqueue.git
cd signqueue
node src/cli.js
node --test
```
